# RSJD GANGSTARS TELUGU

A modern responsive static website starter for RSJD GANGSTARS TELUGU.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Replace placeholder text, YouTube/Instagram links, images, and `videos/song.mp3`.

## Folder structure
- index.html
- style.css
- script.js
- images/
- videos/

## Customize
- Put photos in `images/`.
- Put audio/video assets in `videos/`.
- Update social links in `index.html`.
- The contact form is currently frontend-only.
